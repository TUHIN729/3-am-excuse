One line, in the voice of a hardware wallet that has clocked out for the night: at 3 AM the only thing on duty is the screensaver, and screensavers don't sign. The excuse is the hour itself — it makes no sense at 3 PM, when the wallet is on the clock.

## Run it

```sh
node main.ts
```

This writes the single line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
